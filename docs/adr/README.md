## ADR Format

Each ADR documents:
1. **Context & Problem Statement**: What technical challenge or architectural trade-off we faced.
2. **Decision Drivers**: Factors influencing the technical decision.
3. **Considered Options**: Alternative technologies or design approaches.
4. **Decision Outcome**: The chosen path and rationale.
5. **Pros & Cons**: Trade-offs and consequences.
